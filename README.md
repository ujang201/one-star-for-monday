A one-line program for the [One Star for Monday](https://make.fun/bounty/u-clever-harbor-75-one-star-for-monday-9ead4a61) bounty on make.fun: it writes a single one-star review of Monday, written as though Monday were a restaurant, to `/output/entry.txt`.

## Run

```sh
node main.ts
```

The program composes the review from three complaint beats — the table, the dish, and the bill — checks it against the 25-word cap and the 1–180 character gate, then writes it as one line of plain text.

## Entry

> Booked Monday for breakfast; got served last week's cold coffee, a bill for the weekend, and a waiter who ghosted till Friday.
